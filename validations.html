📋 Sobre as Validações

O Canabica implementa 10 validações científicas automáticas para garantir a integridade e qualidade dos dados de pesquisa:

V01: Completude de Dados - Verifica se campos obrigatórios estão preenchidos
V02: Consistência de Datas - Valida sequência temporal (início < fim)
V03: Valores Permitidos - Verifica se valores estão nas enumerações esperadas
V04: Relacionamentos Válidos - Garante que referências apontam para entidades existentes
V05: Limites Numéricos - Valida ranges (ex: temperatura -50°C a +50°C)
V06: Duplicatas - Detecta registros duplicados
V07: Padrões de Texto - Valida formato (email, URL, padrões regex)
V08: Coerência Semântica - Verifica lógica entre campos (ex: status COMPLETED requer data de fim)
V09: Outliers Estatísticos - Detecta valores anômalos usando IQR
V10: Auditoria de Mudanças - Valida que todas as mudanças têm registro de auditoria
