🔄 Fluxo de Requisição

  1. Cliente faz chamada: api.listStudies()
  2. API Client: Adiciona token, executa interceptors
  3. ApiService: Valida schema, verifica autenticação
  4. Router: Roteia para handler correto
  5. Service: Executa lógica de negócio
  6. Repository: Busca dados do Google Sheets
  7. Resposta: Formata e retorna JSON padronizado
  8. Cliente: Atualiza UI reativamente

Exemplos de Código

          
          
1️⃣ Fazer Login

          

// Login
const response = await api.login('user@example.com', 'password');
console.log('Usuário:', response.user);
console.log('Token:', response.session.token);
          

          
          
2️⃣ Listar Estudos

          

// Listar com filtros e paginação
const studies = await api.listStudies(
  { status: 'ACTIVE', search: 'canabis' },
  { page: 1, pageSize: 20 }
);
console.log('Estudos:', studies);
          

          
          
3️⃣ Criar Estudo

          

// Criar novo estudo
const newStudy = await api.createStudy({
  title: 'Novo Estudo',
  description: 'Descrição do estudo',
  status: 'DRAFT'
});
console.log('Criado:', newStudy);
          

          
          
4️⃣ Usar Componente Reativo

          

// HTML
<study-list auto-load="true"></study-list>

// JavaScript - Escutar eventos
const studyList = document.querySelector('study-list');
studyList.addEventListener('study-selected', (e) => {
  console.log('Estudo selecionado:', e.detail.id);
});
          

          
          
5️⃣ Gerenciar Estado

          

// Ler estado
const state = store.getState();
console.log('Usuário:', state.user);

// Atualizar estado
store.setState({ loading: true });

// Escutar mudanças
store.subscribe('user', (newUser, oldUser) => {
  console.log('Usuário mudou:', newUser);
});
